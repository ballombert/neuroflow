# Structurer un rituel de focus sans friction 🧘

Selon le Dr Russell Barkley, le cerveau TDAH a besoin d'externaliser les repères et de réduire au minimum l'énergie d'activation.

### Micro-étapes atomiques :
- [x] Poser son téléphone hors de portée visuelle
- [x] Mettre son casque audio anti-bruit
- [x] Lancer une session de 5 minutes (Soft-Launch) pour vaincre l'inertie
- [x] Utiliser la jauge spatiale pour ressentir le passage du temps sans anxiété
